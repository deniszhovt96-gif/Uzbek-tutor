# Вопросы для тестов по темам курсов

Приложение «Самоучитель узбекского языка». После чтения темы пользователь проходит короткий тест.
Вопросы ДОЛЖНЫ быть безошибочными: каждый проверяется только по тексту самой темы.

## Источник
`<course>.json` — массив тем: `n`, `title_*`, `express_ru|uz|en` (кратко), `detailed_ru|uz|en` (подробно).
Используй ТОЛЬКО факты из `express_ru` + `detailed_ru` этой темы. Никаких сведений извне, даже если ты уверен.
Узбекские и английские версии текста — для терминологии в переводе вопросов.

## Сколько
- grammar: 6 вопросов на тему; history и civics: 8 вопросов на тему.

## Формат вывода
Один файл JSON (массив), путь укажет задание. Каждый вопрос:
```json
{
  "course": "history", "n": 12, "k": 1,
  "q_ru": "В каком году Амир Темур объединил Мавераннахр?",
  "options_ru": ["В 1370 г.", "В 1336 г.", "В 1402 г.", "В 1405 г."],
  "q_uz": "...", "options_uz": ["...", "...", "...", "..."],
  "q_en": "...", "options_en": ["...", "...", "...", "..."],
  "quote_ru": "в 1370 г. он объединил Мавераннахр под своей властью"
}
```
- `k` — номер вопроса в теме (1…6 или 1…8).
- Ровно 4 варианта; ВЕРНЫЙ ВСЕГДА ПЕРВЫЙ (приложение перемешает). Порядок вариантов одинаков во всех трёх языках.
- `quote_ru` — ДОСЛОВНЫЙ фрагмент (копия символ в символ, 5–40 слов) из `express_ru` или `detailed_ru` этой же темы,
  из которого однозначно следует верный ответ. Проверяется программой: подстрока должна найтись точно.
- Узбекский — латиница с апострофами как в тексте темы: oʻ gʻ (U+02BB), ʼ (U+02BC). Бери термины из `*_uz` текста темы.

## Правила качества
1. Ответ однозначно следует из цитаты; ни один неверный вариант не может оказаться верным по тексту темы
   или по общеизвестным фактам. Неверные варианты — правдоподобные, того же типа (даты — даты, аффиксы — аффиксы),
   и по возможности взяты из той же темы (другая дата, другой правитель), но ТОЧНО неверные для этого вопроса.
2. Проверяй понимание, а не мелочи: ключевые события, причины, правила, формы. Без вопросов «что из перечисленного НЕ…»,
   без «все варианты верны», без вариантов-шуток.
3. Варианты одинаковой длины и стиля, верный не выделяется длиной или формулировкой.
4. Грамматика: вопросы о правилах и формах из текста (какой аффикс, как образуется, перевод формы из текста,
   выбор правильной формы). Узбекские формы — только те, что есть в тексте темы, или образованные строго по правилу,
   которое тема описывает и которое ты в цитате показываешь.
5. Обществознание: НЕ спрашивай конкретные суммы, ставки, сроки, размеры штрафов и пошлин, номера указов — они меняются
   (текст сам просит их сверять). Спрашивай устойчивые принципы, органы, права, порядок действий, номера экстренных служб.
6. История: не спрашивай оценки и спорные трактовки; только факты (кто, когда, где, что основал/построил, чем закончилось).
7. Вопросы внутри темы не дублируют друг друга и не подсказывают ответы друг другу.
8. Перевод на узбекский и английский — точный по смыслу, естественный; даты, имена, термины — как в `*_uz` / `*_en` текстах темы.

Перед записью файла перечитай каждый вопрос: найди цитату в тексте, убедись, что верный ответ из неё следует,
а каждый неверный вариант текстом темы опровергается или не подходит.
