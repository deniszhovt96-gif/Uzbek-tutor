# Правила нормализации (сравнение ответов)

Эти правила реализованы в `scripts/build_vocab.py` и должны одинаково работать
в приложении и в функциях базы (шаг 5). Набор тестовых примеров будет общим.

## Узбекский текст для показа
- Unicode NFC, лишние пробелы схлопываются.
- Любой апостроф (‘ ’ ' ʻ ʼ ` ´) после o/O/g/G → `ʻ` (U+02BB), иначе → `ʼ` (U+02BC).

## Узбекский ключ для сравнения
- Нижний регистр; любой апостроф → `'`; всё, кроме a–z, `'`, пробела и дефиса, → пробел;
  дефис → пробел; пробелы схлопываются; апострофы и пробелы по краям убираются.

## Русский ответ
- Нижний регистр, ё → е; пояснения в скобках удаляются; вся пунктуация → пробел.
- Варианты: вся строка целиком + каждая часть через `,` `;` `/`.
- Узбекское слово → принимаются варианты перевода всех слов с тем же узбекским ключом.
- Русский перевод → принимаются узбекские ключи всех слов с той же строкой перевода (без скобок).

## Полные дубли
- Одинаковые узбекский ключ и русский перевод (со скобками) → одна карточка;
  основная — та, что раньше всех в порядке изучения (CEFR → тема → ID).
