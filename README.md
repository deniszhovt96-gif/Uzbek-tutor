# Uzbek Tutor — самоучитель узбекского языка

Telegram Mini App + Telegram Bot. Работает полностью в облаке:

| Часть | Где | Папка |
|---|---|---|
| Приложение (интерфейс) | GitHub Pages | `app/` |
| База данных и логика | Supabase | `supabase/` |
| Аудио | GitHub Pages (репозиторий uzbek-audio) | — |
| Сборка и выкладка | GitHub Actions | `.github/workflows/` |

Документ с архитектурой и алгоритмом: «Самоучитель узбекского — аудит и архитектура» (claude.ai).

## Структура

```
app/                          приложение (Vite, чистый JavaScript)
  src/main.js                 вход через Telegram, навигация
  src/screens/                вкладки «Дом», «Путь», «Настройки»; сеанс, тренировка, игры, тест уровня
  src/screens/games/          игры: пары, верно/неверно, угадай слово, филворд
  src/exercises.js            генерация 15 видов упражнений
  src/exercise-view.js        отображение упражнений (общее для сеанса и тренировки)
  src/theme.js, src/icons.js  темы оформления, собственные иконки и рисунки карты
  src/session.js              очередь сеанса, повторы ошибок, отправка ответов пачками
  src/normalize.js            нормализация ответов (как в базе)
  src/i18n.js                 тексты RU / UZ / EN
supabase/
  config.toml                 настройки Supabase CLI (для GitHub Actions)
  migrations/                 изменения базы — применяются автоматически
  local-tests/                проверки схемы на локальном Postgres (в Supabase не применяются)
.github/workflows/
  deploy-supabase.yml         применяет миграции к Supabase
  deploy-app.yml              собирает и публикует приложение
```

## Разовая настройка (шаг 1)

### 1. Секреты (Settings → Secrets and variables → Actions → вкладка **Secrets**)

| Имя | Значение |
|---|---|
| `SUPABASE_DB_PASSWORD` | пароль базы (Supabase → Project Settings → Database). Строка подключения собирается в workflow автоматически. |

### 2. Переменная (там же → вкладка **Variables** → New repository variable)

| Имя | Значение |
|---|---|
| `SUPABASE_PUBLISHABLE_KEY` | Supabase → Project Settings → API Keys → **Publishable key** (`sb_publishable_…`). Ключ публичный, его можно видеть всем; защиту данных обеспечивает RLS. |

### 3. GitHub Pages

Settings → Pages → Build and deployment → Source: **GitHub Actions**.

### 4. Запуск

Actions → **Deploy Supabase (база данных)** → Run workflow → дождаться зелёной галочки.
Actions → **Deploy App (приложение на GitHub Pages)** → Run workflow → дождаться зелёной галочки.

Дальше всё запускается само при каждом изменении файлов.

- Бот: уведомление об оплате с командой возврата (копируется нажатием), ответ на `/refund` — кто, тариф, новая дата подписки.

## Шаг 11: правила подписок, экспресс-проверка темы, контрольная

- **Сеанс**: новых слов не меньше половины от «до N новых» (лёгкая — 10, средняя — 13, интенсивная — 15); если новых осталось мало, сеанс добирается повторениями. Слова с ошибкой идут на повторение первыми.
- **«Базовая»**: только лёгкая программа, до 2 сеансов с новыми словами в день (повторение без ограничений). **«Продвинутая»**: любая интенсивность, сеансы без ограничений. Лимиты — `app_config`: `sessions_per_day_free`, `sessions_per_day_basic`, `sessions_per_day_advanced` (0 — без ограничений).
- **Две подписки сразу**: сначала действует «Продвинутая», «Базовая» продолжается после неё на оставшийся срок. Так работают звёзды, коды и выдача администратором.
- **Бот**: `/grant ID|@username basic|advanced 1|3|6|12` — выдать подписку (только администратор); `/id` — пользователь узнаёт свой Telegram ID.
- **Экспресс-проверка темы** (Путь → тема): все невыученные слова темы, ввод перевода; верно — слово сразу получает уровень 15 и вернётся примерно через 3 месяца.
- **Контрольная** (плитка на «Доме»): 20 изученных слов, уровни не меняются, ошибки — в повторение сегодня.
- **Собери слово / филворд / угадай слово**: oʻ, gʻ, sh, ch, ng — одна плитка.
- Ссылка на группу приложения — `app_config.community_url`.

Проверка: `psql … -f supabase/local-tests/test_step11.sql`.

## Шаг 12: уровни слов, разговорная речь, словарь, пятница, пометки, цены

- **Уровни слов перепроверены по каждому слову** (`data/levels.csv`, 3714 изменений): A1 — 533 базовых слова, A2 — 2357, B1 — 3634, B2 — 1336. Тема теперь может быть на нескольких уровнях; на «Пути» она показана на каждом своём уровне (части меньше 6 слов присоединяются к соседнему уровню — `app_config.path_min_group`).
- **Исправлены повреждённые записи словаря** (`data/word_fixes.csv`): обрезанные слова (toʻrt, toʻqqiz, moʻjiza…), перепутанные и неточные переводы; 27 записей, которые нельзя восстановить, отключены. У исправленных слов отключено старое аудио.
- **Короткие примеры для новых слов**: пока слово учится, в заданиях — предложения до 6 слов, потом до 9, дальше любые.
- **Разговорная лексика Ташкента** (`data/source/colloquial.json`, ID с 20001): 349 слов и фраз в 16 темах «Разговорная речь. …», с литературным вариантом и пометкой; без аудио.
- **Словарь**: плитка «Словарь» — уровни, «Изучаю / Все слова», по темам или по алфавиту, поиск, карточка слова с примерами. В листе темы на «Пути» — «Слова темы».
- **Пятница — день повторения**: новые слова открываются после N повторений за день; N = 15 + 1 за каждые 20 начатых слов (не больше 80). Настройки — `review_day*` в `app_config`. Баннер на «Доме», в четверг — предупреждение.
- **Пометки частотности**: пользователи уровня B1+ и администраторы отмечают слова A1/A2 «малоиспользуемое» (→ B1) или «не используется» (→ B2). Администраторам приходит сообщение в бот; решение — Настройки → «Пометки слов». Одобренные уровни сохраняются при повторном импорте словаря (`word_level_overrides`).
- **Филворд растёт**: от 5×5 до 8×8 — по числу решённых филвордов и изученных слов.
- **Проверка вопросов**: варианты показаны вперемешку, верный отмечен ✓ (в самом тесте они перемешиваются случайно).
- **Цены**: «Базовая» 100 000 сум / 450 ⭐ в месяц; 3/6/12 мес. со скидкой 10/15/20%; «Продвинутая» вдвое дороже.
- Плитка «Культура» убрана до появления материалов.

Проверка: `python3 scripts/build_vocab.py`, затем `psql … -f scripts/load_vocab.sql` и `psql … -f supabase/local-tests/test_step12.sql`.

## Шаг 13: статистика, напоминания, знакомство, названия тем, озвучка

- **Расширенная статистика** («Продвинутая»): «Мой прогресс» → прогноз повторений на неделю, ответы по неделям, точность по видам заданий, трудные слова, время занятий. В других подписках — описание с кнопкой «Подписка».
- **Напоминания от бота**: workflow «Напоминания» раз в час (новых секретов не нужно). Ежедневное — в выбранный час, если сегодня не занимались; в четверг — о дне повторения; за 3 дня до конца подписки. Настройки → «Напоминания» (вкл/выкл, время). Кто заблокировал бота — больше не получает (снимается командой /start).
- **Знакомство**: 4 экрана при первом входе (можно пропустить), повтор — Настройки → «Как пользоваться». После 40 изученных слов — одна просьба оставить отзыв в группе. Текст для закрепа в группе — `docs/testers.md`.
- **Названия тем** на узбекском и английском (`data/topic_names.csv`).
- **Озвучка** недостающего аудио — workflow «Озвучка» (`scripts/tts.py`): разговорная лексика, исправленные слова и примеры (~900 файлов). Голос Google (gTTS, как у исходных файлов), запасной — Microsoft. Нужен секрет `AUDIO_REPO_TOKEN` (токен с правом записи в репозиторий uzbek-audio) — иначе файлы скачиваются архивом.

Проверка: `psql … -f supabase/local-tests/test_step13.sql`.

Доступ — «Продвинутая» (2 первые темы — бесплатно).
- **Настройки**: после изменения пункта страница перерисовывается на месте, без загрузки и прокрутки наверх.

## Шаг 15: спряжение и склонение, предложения, числа

- **Примеры в заданиях**: короткие примеры (до 3 слов) — сразу; длинные — только когда пользователь знает на уровень 4+ не меньше 70% остальных слов предложения (`example_ready_pct`, `example_ready_level` в `app_config`). Слова предложения находит сборка словаря (`examples.word_ids`).
- **«Предложения»** — новый блок на главной: готовые длинные примеры как отдельная лексика (перевод, сборка, на слух, пропуск) со своим интервальным повторением.
- **Спряжение** — блок на главной и кнопка у каждого глагола (карточка, задание, словарь): изъявительное наклонение (12 времён), повелительно-желательное, условное, желательное, нереальное, «могу», неличные формы; утвердительные и отрицательные, все лица и числа. Тренировка — 10 форм. Формы строятся по правилам литературного языка для всех ~1 500 глаголов. **Склонение** существительных — падежи, мн. число, притяжательные формы.
- **Грамматический справочник**: темы 21–27 о временах и наклонениях (`data/source/grammar.xlsx`) + 42 вопроса.
- **Числа**: добавлены 10–19, 30–33; исправлены yetti / yetmish / yemoq. При переводе числа с узбекского можно писать цифрами.
- Новые слова из `data/source/supplement.json` (числа и основные глаголы bormoq, kelmoq, demoq…) — озвучить workflow «Озвучка».

Проверка: `psql … -f supabase/local-tests/test_step15.sql`.

## Шаг 16: таблицы спряжения и склонения, диалоги, рекомендации, группа, аналитика

- **Спряжение**: глаголы по уровням (A1→B2, внутри — по алфавиту), у форм — перевод (RU/EN) и разговорные варианты (borgandim, borolaman, borvotti, boripti, borsaydi). Упражнения: «Напишите форму» и «Заполните таблицу» (корень дан — дописать суффикс и окончание, сначала утвердительная, затем отрицательная). У глагола 3 уровня: слово, форма, таблица. Времена открываются по прочитанным темам грамматики (3, 5, 6, 7, 16, 21–27; отрицание — тема 8); потолок уровня = 15 × доля пройденных тем.
- **Склонение** — отдельный блок: существительные по уровням, падежи / мн. число / притяжательные формы (темы 9, 11, 10), свой уровень.
- **⚑ «Нужно исправить»** у каждой таблицы: комментарий уходит администраторам в бот; Настройки → «Пометки форм». Переводы форм — `data/verb_forms.csv`, `data/noun_forms.csv` (сгенерированы, требуют проверки), части речи — `data/pos.csv`.
- **Диалоги** (`data/source/dialogs.json`, 30 шт., A1–B2): чтение с переводом по нажатию и упражнения; пройденный диалог отправляет свои слова в ближайшую очередь заучивания. Так же — слова тем курсов (узбекские термины в скобках). У всех тем курсов есть уровень (`UNIT_CEFR` в `scripts/build_courses.py`).
- **Рекомендации** на главной: слова → тема курса (по очереди грамматика, культура, обществознание, история) → диалог → закрепление.
- **Предложения** по уровням; короткие фразы (2–3 слова) — необязательный бонус.
- **Игры**: «Мои ошибки»; филворд — только в играх, слово засчитывается с любой стороны.
- **Знакомство**: экран «Уже знаете узбекский?» с тестом A1. **Цель недели** (Настройки, 3–7 дней) и **сообщение по понедельникам** в 9:00 с общей статистикой.
- **Групповая подписка** на 3 человек −15%: покупатель получает подписку и 2 кода для друзей (в боте и в «Подписке»).
- **Аналитика** для администратора: Настройки → «Аналитика».
- **Бот обновлён** (`supabase/functions/telegram-bot/index.ts`): вставить код заново в редакторе функции и нажать Deploy.

## Шаг 17: приглашения и купоны −5%

- Личная ссылка в «Подписке»: `t.me/uzbek_tutor_bot?start=ref_КОД` (кнопки «Поделиться» и «Копировать»). Бот запоминает приглашение до первого входа в приложение.

- Купоны личные, без срока. Обычная подписка — 1 купон на оплату; групповая (−15%) — до 3 купонов, каждый −5% на долю одного участника. Работают при оплате звёздами в приложении.
- Возврат: купоны платежа возвращаются, купон автору за этого друга отменяется (если не использован).
- Условия — в приложении («Условия скидок») и в боте (/terms). Статистика — Настройки → «Аналитика» → «Рефералы».
